# 默认 Planner 任务（五段模块化）

以下示例启用心理发现模块。实际目录按当前聊天启用的创作包和主模型版本动态编号；模块编号只用于本次请求。两个上下文模式与调用渠道不变，任务仍追加为最新 User 层消息。全局各段在任务提示词设置编辑，模块的资料与格式在模块编辑器中独立编辑。

## 1. 总任务

来源：全局任务说明

```text
暂停剧情正文生成，根据当前情境选择 Reasoning Skill 与火花，并完成有价值的专项分析。只输出供下一轮正文生成使用的规划结果。
```

## 2. Reasoning Skill / 火花目录

来源：全局目录说明与本轮冻结候选目录

```text
Reasoning Skill 选择：逐项判断当前情境是否符合推荐开启条件，只选严格适用的方法，最多启用五项；可以不选。以下是可选 Reasoning Skill：

001. 视角与知情边界 — 推荐开启：需要判断人物知道什么时

火花选择：根据当前情境选择 0–3 项具体创作素材，可以不选。以下是可选火花：

001. 生活中的具体细节 — 推荐开启：本轮适合加入生活气息时
```

## 3. 分析模块指导

来源：全局调度说明与本轮适用模块分析资料（按用户排序）

```text
以下模块分别提供专项观察与构思任务。先判断本轮最值得投入创作精力的内容；有价值的模块充分展开具体、独特、符合当前情境的发现，不急于采用第一个常见答案。当前不适用或没有明显内容增益的模块，最终输出「无」。各模块各司其职，不为填满格式重复分析。

<analysis_modules>
<module id="1" name="心理发现">
三、心理发现

1. 本轮情感核心：提炼当前最值得深入探索的心理问题，尤其关注人物尚未确认的他者心意、私人矛盾与意外的情感可能性。

2. 人物心理发现：针对最关键的1～2名人物，充分展开有价值的他者心智探索、复合情感、私人欲望、历史重估与反事实可能。
</module>
</analysis_modules>
```

## 4. 输出总协议

来源：全局输出协议

```text
只输出规划结果，不生成剧情正文。Reasoning Skill 与火花选择标记遵循下方格式，只使用本轮目录编号。分析模块按指定顺序输出，不适用的模块输出「无」。分析结果是供 Generation 采用的候选素材，不自动成为已发生事实。优先输出具体、有价值的发现，省略空泛过程和无意义总结。XML 风格标签仅用于划分提示词中的资料边界，分析正文不必复现这些标签。
```

## 5. 具体输出格式

来源：选择标记、分析模块输出总起与本轮适用模块格式

```text
Reasoning Skill 选择标记：[reasoning skill: 001, 005]
火花选择标记：[spark: 001, 002]
未选择时冒号后留空。

以下为各分析模块的输出格式。按本轮编号和名称依次呈现结果；每个模块使用 Markdown 标题标明名称，不适用时在标题下只写「无」。

<analysis_module_formats>
<module id="1" name="心理发现">
三、心理发现

1. 本轮情感核心：提炼当前最值得深入探索的心理问题，尤其关注人物尚未确认的他者心意、私人矛盾与意外的情感可能性。

2. 人物心理发现：针对最关键的1～2名人物，充分展开有价值的他者心智探索、复合情感、私人欲望、历史重估与反事实可能。
</module>
</analysis_module_formats>
```
