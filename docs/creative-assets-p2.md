## 实际数据关系

| 概念 | 实际存储与作用 |
| --- | --- |
| 创作包 | 绑定世界书根对象 `spark_planner.packs` 中的逻辑分组。Skill 的 `packId` 指向它，分析模块也在同一根对象下按 `packId` 归属。不是一包一世界书。 |
| 正在浏览的包 | `library.js` 的界面状态 `selectedPack`。切换浏览只换展示，不改变启用组合。包管理复用此状态，不维护另一份独立选中包。 |
| 当前聊天启用组合 | `chatMetadata.spark_planner.enabledPackIds`。数组存在时是聊天独立覆盖；不存在时继承世界书中的默认组合。 |
| 全局默认组合 | 绑定世界书根对象的 `defaultEnabledPackIds`。所有使用这份世界书且未覆盖的聊天继承它；不是跨世界书共享资产注册表。 |
| 绑定世界书 | 扩展设置 `world` 指定同一注入载体，同时承担创作资产的实际持久化：包注册表、Skill 元数据/正文/版本、分析模块、插入配置均在其中。 |
| 插件镜像 | 用 `spark_planner.owner` 明确标记的 Skill、指导及 ECoT 附属条目。持久化保持 `disable=true`；普通世界书条目不被接管。Skill 主条目保存默认版镜像和版本元数据；指导/ECoT 是可修复的派生镜像。 |
| 本轮注入 | 规划应用不永久启用世界书条目。Generation 激活时解析版本并冻结，`overlayLore` 移除本插件旧扫描副本，然后将选中内容提供给原生世界书扫描。 |

更换绑定只是切换资产来源，不迁移、删除或合并旧世界书。新建逻辑包复用有效绑定。没有有效绑定时，在创作库的新建流程内提供一次性专用世界书创建或已有世界书选择；完成后输入包名、创建并切到新包。新包不自动启用。首次初始化仍保留原注册表机制创建的默认包，不擅自重命名它或改变已有启用组合。原有事务、备份、UID、ECoT 关联及非插件条目保护继续使用。

设置的“世界书注入配置”默认折叠，外部显示未配置、已就绪、无法读取或镜像同步异常。手动绑定、专用世界书创建、原生编辑器、指导镜像选择、备份恢复和调试都收在该区域。恢复仍只处理插件拥有的数据。

## 页面归属与检索

| 页面 | 功能 |
| --- | --- |
| 当前 | 三种模式、启用包概览/配置跳转、本轮选材与策略、指导、应用/审核继续、正文重生成/重规划、预计注入、Token 开销。 |
| 历史 | 规划/正文执行摘要、历史正文与指导、原始 Planner 输出、实际装配及最新素材/历史快照恢复。 |
| 创作库 | 包新建/描述/复制/删除/导入导出、可选火花目录、分类、聊天与全局组合；Skill 与火花、分析模块两个子页签。 |
| 设置 | 模型渠道/匹配、Planner 参数/任务提示词、指导插入配置、世界书注入配置、调试与历史保留。 |

当前聊天从继承切到独立配置时复制当前有效组合。编辑全局默认必须显式保存；已有聊天覆盖不变。切回继承删除覆盖字段。分析模块原有排序、长期开关、归属、版本、分析/输出格式和 P1 注入方式不变；每行分别显示模块开关、包启用、版本可用性和下次 Planner 是否参与。

检索范围包含当前包、当前聊天启用包和全部包。搜索标题、启用条件及各版本正文；类型、分类、长期可选开关、本轮选择状态可组合筛选。跨包结果直接打开原编辑器，显示类型、包名与条件摘要。搜索值、范围、筛选和折叠/滚动继续由界面状态维护；每个浏览包记住其分类展开、分类筛选及滚动位置。没有增加条目列表内部滚动容器。

## 历史快照与兼容

仍使用聊天元数据的 `history`。Planner 记录保留 `raw`、`parsed`、`plan`、`applied`、原请求与诊断。`parsed`/`original` 表示 AI 自主选材，`selected` 表示最终方案；人工必选不混进原始 AI 选择。

新增 `record.generation` 在非 dry-run 的 `GENERATE_AFTER_DATA` 边界生成，来源为已冻结的本次 `active`，不是 Planner 草稿或实时创作库。尚未走到这个边界的记录没有实际正文快照。记录包含：

- 聊天/轮次、原生生成类型、目标索引、成功后的回复索引及 swipe 版本、方案 revision、来源与时间。
- 真实可取得的 Planner 模型和 Generation 模型，未知时保留空值；不会从 UI 名称猜测模型。
- 最终选材 ID、请求选择与实际可装配选择、最终指导、各项稳定 ID/标题/包名/适配版本/正文。
- 原生插入字段及 ECoT 内容；指导原来为空时另存空正文的插入模板，以便恢复后新增指导。
- 明确标记为估算的插件文本 Token 量、请求中/成功/失败/取消/刷新中断结果。

每次新的正文执行独立记一条记录；首个执行可附在原 Planner 记录上，之后 Swipe/Regenerate 各自新增，旧快照不被覆盖。手动方案和复用方案也在实际边界记录。Planner 原始输出和解析结果继续保存；素材后续编辑或删除不影响历史正文。

旧记录不补写猜测内容，界面显示“此记录未保存实际正文快照”。仍可恢复其选材和指导并使用最新素材，不能选择历史快照。历史中的“编辑创作库当前版本”是独立入口，已删除素材提示不存在。

默认保留最近 50 条，设置可调整为 1–500。修改上限不会立即清理；新记录加入时按明确规则保留。因该规则淘汰的旧轮次、且没有保留记录引用的执行方案可一起释放，当前方案保留。可主动清理当前聊天历史。没有启动时自动清空或迁移已有历史。

## 复用与生成

- 默认“使用最新素材”复制选材 ID 与指导为未应用草稿，读取当前资产并按当前 Generation 模型解析版本。删除、禁用、包停用或版本不适用均提示；不会换成其他 ID。应用时沿用 P1 的无效项移除和重新确认。
- “使用历史快照”复制实际正文、版本与插入配置；不重新匹配当前模型、不要求原素材还存在、不写回素材世界书。实际 Generation 使用的模型仍独立记录。可删减快照已有选材、编辑指导；新增快照中没有的条目时提示改用最新素材，防止混用来源。
- “仅重生成正文”应用当前草稿并走原生 `generate('regenerate')`，显式跳过 Planner，保留原生替换回复及失败恢复语义。
- “重新规划并生成”清除当前轮旧方案，让同一原生 Regenerate 拦截重新运行 Planner。审核模式保留原生操作等待确认；手动模式不提供 Planner 操作。
- 历史恢复只复制创作方案，随后由用户应用/生成。不修改聊天历史、角色卡或其他世界书状态，不重发玩家消息。

异步恢复、应用和激活继续检查聊天、绑定、revision、取消 epoch；迟到结果不能覆盖另一聊天或更新后的草稿。恢复到没有玩家消息的聊天时使用待用方案机制，不伪造玩家消息。

## 预计注入、实际装配与 Token

`injection.js` 统一调用原来的 `overlayLore` 生成预览和快照。实际装配中的版本解析仍使用 `Workflow.resolveEntries`；历史快照装配直接使用冻结正文。每次打开预计预览都读取当前草稿；草稿变化会更新下次预览与防抖开销概览，预览本身不创建或应用草稿。

预览包含正文、版本、包、角色/深度/顺序/Outlet 等原生配置及逐项和分类 Token 数，可复制。当前页另有“本轮上次实际装配”，只读取当前聊天/轮次的最近一次持久快照，不随草稿编辑改变。预计文本计数优先复用宿主 tokenizer，失败用字符估算；运行概览区分候选目录、分析/格式配置与 Generation 的 Reasoning、火花、指导和总计。实际历史保存当时可同步取得的估算，不用当前模型重新计算后冒充历史用量。

范围限制始终显示：这只是火花规划器提供给原生世界书扫描的装配内容，不是完整 Generation Prompt。原生预算、概率、触发条件、Outlet 消费者、参数替换与上下文裁剪可能进一步改变结果。快照记录装配/请求边界与运行结果，不声称逐项最终入模或模型真实计费 Token。P1 的标签外分析不会被预览自行重新拼回。

## 单轮选材策略

聊天元数据的 `selectionPolicy` 按聊天与绑定隔离，保存临时 `items` 与 revision，不改素材长期设置或包启用状态。手动模式仍直接勾选。

自动/审核模式可提前设置自动、必选、排除。运行前先经过正常包、条目 enabled 和 Generation 版本校验。不可用必选阻止 Planner 并提示。必选与排除都从自主编号目录移出，排除不能通过解析结果启用；必选只用标题/条件简述给 Planner，代码在解析后去重加入。AI 仍可另外使用原自主 Reasoning / 3 个火花名额。

请求期间冻结策略。首个成功生成前，AI 方案应用时也防止通过普通勾选绕过当前冻结的必选/排除；必选失效时要求修复/重规划。审核重规划、取消和失败重试保留策略。成功清除对应 revision；若玩家在运行期间设置了新 revision，旧请求完成不会清掉新设置。可手动清空，切聊天不会带入其他聊天。

没有重写用户任务、分析模块或默认创作 Prompt；唯一新增的模型指令是本轮已确定使用素材的简短说明。选材约束由代码执行，不依赖模型承诺。
