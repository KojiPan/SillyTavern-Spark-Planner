# Spark Planner｜火花规划器

SillyTavern 双阶段剧情规划与创作素材管理插件。

**Beta · 0.7.0**，最低支持 SillyTavern **1.18.0**。已在官方 1.18.0、1.19.1 的隔离环境进行模拟模型集成验证，真实模型效果仍需按自己的角色和预设调整。

## 简介

火花规划器让 AI 在正式生成剧情前，先进行一次独立规划：理解当前人物关系与情境，发现值得深入演绎的心理、互动和创作机会，并从用户维护的创作库中选择适用的 Reasoning Skill 与火花。

规划结果可人工查看、修改和重新应用，随后交由 SillyTavern 正常生成剧情。插件提供创作内容的管理与调度，不附带私人角色、世界书或个人素材。

## 主要功能

- **Planner → Generation**：正常发送消息时先规划，再使用酒馆原生成流程输出正文；也可仅规划、手动修改后继续生成。
- **动态选择**：Planner 从当前有效目录选择 Reasoning Skill 与火花，两类内容分别编号和限制数量。
- **创作包与分类**：支持新建、导入、导出、复制、删除和跨包移动；包启用组合可按聊天配置。
- **模型专用版本**：默认版与模型专用版分别编辑，通过共享标签和匹配规则选择适用内容。
- **可组合分析模块**：手动启用和排序，各版本独立保存分析资料与输出格式；支持跨包移动，不占条目选择名额。
- **世界书插入配置**：复用原生位置、角色、深度、顺序、概率和 Outlet；Reasoning Skill 可附加独立的 ECoT 提问。
- **历史与人工控制**：查看原始输出、实际请求快照，修改或复用规划；Swipe / Regenerate 复用当前轮规划。
- **Planner 上下文与渠道**：支持沿用酒馆预设或独立基础预设，可继承主模型连接或使用独立 Planner 渠道。

## 安装

1. 打开 SillyTavern 的扩展管理页面，点击「安装扩展」。
2. 粘贴以下仓库地址并确认安装：

   ```text
   https://github.com/KojiPan/SillyTavern-Spark-Planner
   ```

3. 安装完成后刷新页面。在酒馆魔棒菜单中打开「火花规划器」。

仓库根目录直接提供 `manifest.json`、`index.js`、CSS 和必要资源，无需运行 npm 安装或构建。后续可通过酒馆扩展管理界面检查更新。

如已有手动安装的旧版本，请先备份自己的配置与创作内容，避免同时加载两份插件。安装插件本身不会替你迁移另一份酒馆的个人数据；需要搬运素材时，请单独导出、导入创作包。

## 基本使用

1. 安装插件，打开魔棒菜单中的「火花规划器」。
2. 在设置中绑定或新建专用世界书，配置 Planner 渠道；也可以继承酒馆主模型连接。主连接为 Text Completion 时，Planner 需使用独立 Chat Completion 渠道。
3. 在「创作库」导入或建立创作包，添加 Reasoning Skill、火花等条目，并启用需要的创作包。
4. 按需在设置中启用分析模块，打开规划器总开关。
5. 正常发送消息，体验 Planner → Generation；在「当前」页查看结果，修改后点击「应用修改」。

Reasoning Skill 用于指导正文的判断与演绎，火花提供具体创作素材，分析模块指导 Planner 进行专项观察与构思。分析结果是候选创作指导，不自动视为已经发生的剧情事实。

## Beta 限制与反馈

- 规划会额外产生一次模型请求，增加时间与 Token 用量；真实模型可能不完全遵循选择格式。
- 已有心理发现会迁移为分析模块；旧自定义混合协议保留原文，若出现迁移提示，请检查并拆分全局规则与模块格式。
- 所有 Provider、第三方扩展组合、群聊工具循环和真实手机软键盘尚未全面验证。
- Outlet 需要预设中的对应引用；最终插入仍受酒馆原生世界书预算、概率和其他规则影响。
- 实际请求快照包含当前聊天上下文，仅用于本地查看。反馈问题时请先去除密钥、私人地址、聊天和角色内容。

问题与建议请提交到 [GitHub Issues](https://github.com/KojiPan/SillyTavern-Spark-Planner/issues)，附上酒馆版本、插件版本和可公开的复现步骤。
