# Spark Planner｜火花规划器

SillyTavern 双阶段剧情规划与创作素材管理插件。

**Beta · 0.8.0**，最低支持 SillyTavern **1.18.0**。已在官方 1.18.0、1.19.1 的隔离环境进行模拟模型集成验证，真实模型效果仍需按自己的角色和预设调整。

## 简介

火花规划器让 AI 在正式生成剧情前，先进行一次独立规划：理解当前人物关系与情境，发现值得深入演绎的心理、互动和创作机会，并从用户维护的创作库中选择适用的 Reasoning Skill 与火花。

规划结果可人工查看、修改和重新应用，随后交由 SillyTavern 正常生成剧情。插件提供创作内容的管理与调度，不附带私人角色、世界书或个人素材。

## 主要功能

- **三种运行模式**：「当前」页切换自动规划、审核后生成、手动编排；审核保留原生生成操作，手动编排无需 Planner 历史或模型调用。
- **本轮创作指导**：默认以可阅读的正文展示，标题旁可复制、编辑；编辑器共用放大、清空与 Token 工具栏，保存为新草稿，原始输出独立保留。
- **统一指导交付**：所有 Planner 分析仅交付完整 `<guidance>...</guidance>` 内的内容；无标签为空，不回退全文。玩家手写指导直接使用。
- **动态选择**：Planner 从当前有效目录选择 Reasoning Skill 与火花，两类内容分别编号和限制数量。
- **创作包与分类**：支持新建、导入、导出、复制、删除和跨包移动；包启用组合可按聊天配置。
- **模型专用版本**：默认版与模型专用版分别编辑，通过共享标签和匹配规则选择适用内容。
- **生成期间编辑**：Planner 或正文生成时仍可编辑素材、开关和配置；修改在后续请求装配时生效。
- **快捷编辑与 Token 统计**：本轮标签按 Reasoning Skill / 火花分组，点击查看、长按或右键编辑；多行编辑支持右下角鼠标/触控调高、放大与防抖 Token 统计。
- **可组合分析模块**：手动启用和排序，各版本独立保存分析资料与输出格式；支持跨包移动，不占条目选择名额。
- **世界书插入配置**：复用原生位置、角色、深度、顺序、概率和 Outlet；Reasoning Skill 可附加独立的 ECoT 提问。
- **历史与人工控制**：查看原始输出、实际请求快照，修改或复用规划；Swipe / Regenerate 复用当前轮规划。
- **P2 创作资产与实验**：创作库内初始化/新建包、跨包正文搜索、分析模块及聊天组合管理；历史保存逐次正文装配快照，支持最新素材或历史正文恢复、仅重生成正文、注入预览和单轮必选/排除。详细数据关系、兼容与验证见 [P2 实施说明](docs/creative-assets-p2.md)。
- **Planner 上下文与渠道**：支持沿用酒馆预设或独立基础预设，可继承主模型连接或使用独立 Planner 渠道。

## 安装

1. 打开 SillyTavern 的扩展管理页面，点击「安装扩展」。
2. 粘贴以下仓库地址并确认安装：

   ```text
   https://github.com/KojiPan/SillyTavern-Spark-Planner
   ```

3. 安装完成后刷新页面。在酒馆魔棒菜单中打开「火花规划器」。

仓库根目录直接提供 `manifest.json`、`index.js`、CSS 和必要资源，无需运行 npm 安装或构建。后续可通过酒馆扩展管理界面检查更新。

如已有手动安装的旧版本，请先备份自己的配置与创作内容，避免同时加载两份插件。安装插件本身不会替你迁移另一份酒馆的个人数据；需要搬运素材时，请单独导出、导入创作包。

## 基本使用

1. 安装插件，打开魔棒菜单中的「火花规划器」。
2. 进入「创作库」新建创作包，输入名称即可；首次使用会在同一流程中初始化专用世界书或选择已有世界书，之后新包共用此绑定。创建后可直接启用当前浏览包，或在创作包管理中配置当前聊天组合及全局默认组合。
3. 在创作库添加、导入或编辑 Skill 与火花，切到「分析模块」启用和配置专项分析。按需在设置中配置 Planner 渠道，也可以继承酒馆主模型连接；主连接为 Text Completion 时，Planner 需使用独立 Chat Completion 渠道。
4. 打开规划器总开关。自动/审核模式可为个别条目设置本轮必选或排除；不会修改长期可选开关。
5. 在「当前」页选择模式：自动规划后直接生成；审核模式修改方案后点击「继续生成正文」；手动模式调整选材和指导，点击「应用本轮方案」后使用酒馆发送或生成。
6. 在当前页展开「全部注入材料」阅读预计正文，或在底部「更多」选择重生成与「本轮运行诊断」。历史可按最新素材或历史装配快照恢复草稿；快照不随素材后续修改/删除而变化。

所有创作包共用绑定世界书，资产正文也实际保存在其中。设置中的「世界书注入配置」用于高级绑定、镜像修复和备份；更换绑定只切换资产来源，原内容保留，不会自动迁移。

Reasoning Skill 用于指导正文的判断与演绎，火花提供具体创作素材，分析模块指导 Planner 进行专项观察与构思。分析结果是候选创作指导，不自动视为已经发生的剧情事实。

从本轮标签进入编辑器时，会打开本轮匹配的适配版本。正文附近会显示正在编辑的版本名称；版本切换、新增、删除与匹配优先级位于默认折叠的「模型适配」中。保存后保留创作库的搜索、分类展开和浏览位置。

创作库共用一个纵向滚动区域。分类标题会吸附在固定页签下方，滚动进入下一分类时自然替换；在长列表中点击吸顶标题即可折叠并返回该分类附近。工具栏更多菜单中的「全部折叠」可返回分类总览，同时保留当前搜索条件。

多行编辑框可从右下角拖动调高，保存重开、普通状态和 Token 刷新会保留本次使用中的高度；放大编辑继续可用。文本框只显示右对齐的 `Token：398` 或 `≈Token：398`。无法确认 tokenizer 与目标模型准确匹配时保留约等于标记，不代表完整请求或计费用量。

「全部注入材料」与历史装配快照共用只读组件，指导优先阅读、各素材按需展开。复制全部保持装配原始顺序，不添加 UI 标题、说明、统计或配置。完整请求、模型适配和阶段时间线在运行诊断中查看。

诊断可观察浏览器实际向酒馆发送的 Planner/Generation 请求，保留消息角色与顺序，不修改请求。**酒馆最终消息没有逐素材来源映射，当前不声称能确认各项实际注入**；界面显示“实际注入记录不可用”，装配快照仍按 P2 语义保留及复用。服务端供应商转换不在浏览器观测范围内。新增完整请求正文最多保留最近 5 份、每份 50 万字符、合计 150 万字符；超限明确标记，历史与素材不删除。

设置首页为分组目录，Planner 任务提示词可直接展开编辑。独立渠道可在保存前自动获取模型、搜索真实 ID、测试生成及手动回退；已有模型不会因刷新静默替换，Key 保存在酒馆密钥库。详见 [UX-02](docs/ux02.md)、[本次 UI 与诊断实现](docs/ux03.md) 和 [长期 UI/UX 规范](docs/ui-design-guidelines.md)。

## Beta 限制与反馈

- 自动与审核模式会额外产生一次 Planner 请求；手动编排不调用 Planner。真实模型可能不完全遵循选择格式或模块标题，标签提取失败时对应模块不交付内容。
- 关闭面板保留待审核操作；刷新页面或切换聊天会终止原生调用，需要通过酒馆重新发起生成。本轮确认方案可供显式重生成、续写及失败重试使用，新一轮不会自动继承。
- 已有心理发现会迁移为分析模块；旧自定义混合协议保留原文，若出现迁移提示，请检查并拆分全局规则与模块格式。
- 所有 Provider、第三方扩展组合、群聊工具循环和真实手机软键盘尚未全面验证。
- Outlet 需要预设中的对应引用；最终插入仍受酒馆原生世界书预算、概率和其他规则影响。
- 实际请求快照包含当前聊天上下文，仅用于本地查看。反馈问题时请先去除密钥、私人地址、聊天和角色内容。

问题与建议请提交到 [GitHub Issues](https://github.com/KojiPan/SillyTavern-Spark-Planner/issues)，附上酒馆版本、插件版本和可公开的复现步骤。
